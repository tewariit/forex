# Forex Playbook — 17 กลยุทธ์ (Mario Singh)

เว็บ static ช่วยจัดระเบียบระบบเทรด: playbook กลยุทธ์ + เช็กลิสต์ก่อนเข้าไม้ + คำนวณขนาดไม้ + trade journal
ไม่มี backend ข้อมูลทุกอย่างเก็บใน localStorage ของเบราว์เซอร์เครื่องนี้เท่านั้น

## วิธีเปิด

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือรันเป็นเซิร์ฟเวอร์ (แนะนำ — localStorage เสถียรกว่า):

```bash
python -m http.server 5173
```

แล้วเปิด http://localhost:5173

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บทั้งหมด (5 แท็บ) |
| `assets/js/strategies.js` | **ข้อมูลกลยุทธ์ — แก้ที่นี่ที่เดียว** |
| `assets/js/app.js` | ตรรกะ: filter, drawer, เซสชัน, คำนวณ, journal, สถิติ |
| `assets/css/style.css` | ธีมมืด |

## 5 แท็บ

1. **กลยุทธ์** — การ์ด 18 หัวข้อ (17 กลยุทธ์ · Commodity Correlation แยก 2 ตอน) กรองตามสไตล์/ค้นหา/เฉพาะที่เซสชันเปิดอยู่ คลิกการ์ดเพื่อดูเงื่อนไขเข้า-ออก ความเสี่ยง เช็กลิสต์ และช่องโน้ตส่วนตัว
   แต่ละการ์ดมีลิงก์ด่วนไปกราฟ TradingView (ตั้ง symbol + time frame ให้ตรงกับกลยุทธ์อัตโนมัติ) และปฏิทินข่าว ในหน้ารายละเอียดจะมีลิงก์กราฟครบทุกคู่เงินของกลยุทธ์นั้น พร้อมปฏิทินข่าว 3 แหล่ง (ForexFactory / Investing.com / TradingView)
2. **เซสชัน** — เวลาเปิด-ปิดตลาดเป็นเวลาไทย คำนวณจาก timezone จริงจึงเลื่อนตาม DST เอง
3. **คำนวณขนาดไม้** — lot จาก %risk + ระยะ SL พร้อมภาพผลถ้าโดน SL ติดกัน 5 ไม้ และ win rate ที่ต้องมีเพื่อเสมอตัว
4. **Journal** — บันทึกไม้เทรด ส่งออก/นำเข้า JSON
5. **สถิติ** — win rate, profit factor, P/L รายกลยุทธ์, % การทำตามกฎ

## สถานะข้อมูล

**ถอดจากต้นฉบับครบทั้ง 17 กลยุทธ์แล้ว** ทุกการ์ดมีฟิลด์ `source` ระบุเลขหน้าจริง และป้ายบนการ์ดคำนวณจากฟิลด์นี้อัตโนมัติ:

- มี `source` → 🟢 "ถอดจากต้นฉบับ"
- ไม่มี `source` → 🟡 "ยังไม่ได้เทียบต้นฉบับ" (พร้อมกล่องเตือนในหน้ารายละเอียด)

แต่ละการ์ดมีฟิลด์ `bookExample` เก็บตัวเลขราคาเข้า/SL/TP จากตัวอย่างในหนังสือ และ `notes` เก็บข้อมูลประกอบ

### แก้ไข/เติมข้อมูลเพิ่ม

- ชั่วคราว: ช่อง "โน้ตของฉัน" ในหน้ารายละเอียด (บันทึกลง localStorage อัตโนมัติ)

### สินทรัพย์ที่ใช้

`WATCHLIST` บรรทัดแรกของ `strategies.js` คือรายการกลางที่กลยุทธ์แบบไม่ผูกสินทรัพย์จะดึงไปใช้ ส่วนกลยุทธ์ที่หนังสือระบุสินทรัพย์เจาะจงจะมีฟิลด์ `symbols` ของตัวเอง (เช่น CAD/JPY + น้ำมัน, XAU/USD + ดัชนีดอลลาร์, GBP/JPY, GBP/USD, USD/JPY, AUD/USD)
